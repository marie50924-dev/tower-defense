# まほうのおかしの国をまもって 🍬

パステルカラーのかわいいタワーディフェンスゲームです。HTML5 Canvas で作られていて、スマホでもPCでも遊べます。

## 遊び方

道を歩いてくる敵から、おかしの国を守るゲームです。

1. 下のメニューから置きたいおかしを選ぶ
2. 道以外の場所をタップして設置する
3. 「つぎのウェーブ ▶」を押すと敵がやってくる
4. 敵を倒すとおほしさま（⭐）がもらえるので、おかしを増やしたり強くしたりする

敵が道を通りぬけるとハートが1つ減ります。ハートが0になるとゲームオーバーです。30ウェーブ守りきればクリアです。

### おかしの種類

| おかし | ねだん | とくちょう |
|---|---|---|
| 🍬 キャンディ | ⭐50 | すばやく1体をねらう。序盤の主力 |
| 🍧 アイス | ⭐70 | あてた敵をおそくする。攻撃力は低い |
| 🍫 チョコ | ⭐110 | まわりの敵もまとめて攻撃する |
| ⭐ スター | ⭐160 | 遠くまでとどく強力な一撃 |

置いたおかしをタップすると、強化（最大Lv.3）と売却ができます。強化すると攻撃力が1.6倍、射程が1.12倍、連射速度が上がります。売却するとそれまでに使ったおほしさまの60%が戻ります。

### コツ

- カーブが多いところは敵が長くとどまるので、おかしを置くと効率がいいです
- アイスで足を止めて、まわりのキャンディやチョコで削るのが強いです
- 新しく置くより、既にあるおかしを強くした方が安く済むことがあります
- 「2x」ボタンで倍速にできます。待ち時間を減らしたいときに便利です

### 敵の種類

| 敵 | とくちょう |
|---|---|
| スライム | 基本の敵 |
| ぴょん | 素早いが体力が低い（ウェーブ3から） |
| もちもち | 遅いが体力が高い（ウェーブ5から） |
| ボス | 10ウェーブごとに出現。通されるとハートが5つ減る |

ウェーブが進むごとに敵の体力が増えていきます。

## 技術的なこと

HTMLファイル1つだけで動きます。外部ライブラリも、画像ファイルも、音声ファイルも使っていません。

- **描画** — Canvas 2D。キャラクターはすべてコードで描いています（円・グラデーション・ベジェ曲線の組み合わせ）。ふわふわ揺れる動き、敵のぷにぷにした伸縮、キラキラのパーティクルを入れています
- **効果音** — WebAudio でその場で生成しているため、音声ファイルは不要です。♪ ボタンでオン・オフできます
- **経路** — 曲がり角の座標だけを定義し、そこから道のマスと敵の移動経路を自動生成しています。マップを変えたいときは `WAY` の配列を書き換えるだけです
- **表示** — `devicePixelRatio` に対応しているので高解像度画面でもぼやけません。画面サイズに合わせてマスの大きさが自動で変わります
- **操作** — Pointer Events を使っているので、タッチでもマウスでも同じように動きます

### 調整しやすいところ

ゲームバランスはファイル上部の設定オブジェクトにまとまっています。

- `TOWERS` — おかしの値段・攻撃力・射程・連射速度
- `ENEMIES` — 敵の体力・速さ・もらえるおほしさま
- `waveList()` — 各ウェーブに出てくる敵の組み合わせ
- `hpScale()` — ウェーブごとの体力の増え方
- `WAY` — 道の形

## 動かし方

`index.html` をブラウザで開くだけです。サーバーは必要ありません。
